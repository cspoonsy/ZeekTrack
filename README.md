# choochoo

## Overview

choochoo is a Lego-based train simulation used to stage attack/defend exercises. It pairs a physical Lego train setup with network monitoring so that adversarial actions and defensive detections can be demonstrated against a tangible, real-world target.

## What It Demonstrates

- Attack/defend scenarios against a physical (Lego) train system
- Corelight network visibility and detection over the simulation's traffic
